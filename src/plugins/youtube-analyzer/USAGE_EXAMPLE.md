# YouTube 视频分析工具使用示例

## 快速开始

### 1. 准备工作

#### 获取 BigModel API Key

1. 访问 [BigModel 开放平台](https://open.bigmodel.cn/)
2. 注册账号并登录
3. 在控制台中创建 API Key
4. 复制 API Key（格式类似：`your-api-key-here`）

### 2. 使用步骤

#### 步骤一：配置 API Key

1. 打开 ToolsHub 应用
2. 在首页找到"YouTube 视频分析"工具并点击
3. 在"API 配置"区域，粘贴你的 BigModel API Key
4. 点击"保存"按钮（API Key 会被安全地保存在本地）

#### 步骤二：输入视频链接

在"视频链接"输入框中，粘贴 YouTube 视频链接。支持以下格式：

- 标准链接：`https://www.youtube.com/watch?v=dQw4w9WgXcQ`
- 短链接：`https://youtu.be/dQw4w9WgXcQ`
- 视频 ID：`dQw4w9WgXcQ`

#### 步骤三：开始分析

1. 点击"🚀 开始分析"按钮
2. 工具会自动执行以下步骤：
   - 🎯 获取视频字幕
   - 🤖 调用 AI 进行分析
   - 📊 生成分析报告

#### 步骤四：查看报告

分析完成后，你可以：

- **👁️ 预览报告**：在新窗口中查看完整报告
- **💾 下载报告**：保存为 HTML 文件，可以离线查看或分享

## 使用场景示例

## 常见问题

### Q1: 视频没有字幕怎么办？

**A**: 目前工具只支持有字幕的视频。如果视频没有字幕，请：
- 检查视频是否有自动生成的字幕（YouTube 会自动为部分视频生成字幕）
- 选择其他有字幕的视频

### Q2: 分析需要多长时间？

**A**: 通常需要 1-3 分钟，具体取决于：
- 视频长度（字幕数量）
- 网络速度
- API 响应时间

### Q3: API 调用失败怎么办？

**A**: 请检查：
- API Key 是否正确
- 网络连接是否正常
- API 配额是否用完
- BigModel 服务是否正常

### Q4: 生成的报告准确吗？

**A**: 报告由 AI 生成，具有以下特点：
- ✅ 能够准确提取主要信息
- ✅ 逻辑结构清晰
- ⚠️ 可能存在理解偏差
- ⚠️ 建议结合原视频使用

### Q5: 可以分析非英文视频吗？

**A**: 可以！只要视频有字幕，工具支持：
- 中文视频
- 英文视频
- 其他语言视频（需要有对应语言的字幕）

### Q6: 报告可以编辑吗？

**A**: 生成的 HTML 报告可以：
- 在浏览器中打开编辑
- 使用文本编辑器修改源代码
- 导出为 PDF 或其他格式

### Q7: 如何分享报告？

**A**: 你可以：
- 直接发送 HTML 文件
- 将报告托管到网站
- 打印为 PDF
- 复制内容到文档

## 最佳实践

### 1. 选择合适的视频

✅ **推荐**：
- 有明确主题的教学视频
- 结构清晰的演讲
- 信息密度高的访谈

❌ **不推荐**：
- 音乐视频（字幕少）
- 娱乐搞笑视频（内容分析价值低）
- 超长视频（可能超过 API 限制）

### 2. 合理使用 API 配额

- 避免重复分析同一视频
- 保存重要的分析报告
- 定期检查 API 使用情况

### 3. 结合原视频使用

- 先看报告了解大纲
- 再观看视频深入理解
- 对比报告验证理解

### 4. 建立知识库

- 按主题分类保存报告
- 定期回顾重要报告
- 建立个人知识体系
